## Project Overview

Personal website for a psychotherapist (Mgr. Petr Davídek) based in Brno, Czech Republic. All content is in Czech. The site uses Czech-language URL routing via Next.js rewrites (e.g., `/o-mně` → `/about`).

## Commands

- `pnpm run dev` — Start development server
- `pnpm run build` — Production build (automatically runs `next-sitemap` via postbuild)
- `pnpm run start` — Start production server
- `pnpm run lint` — ESLint (next/core-web-vitals)

## Architecture

**Stack:** Next.js 15 (App Router), React 18, TypeScript, Tailwind CSS 3, pnpm

**Routing:** App Router (`app/`). Czech URL paths are mapped via rewrites in `next.config.js` (e.g., `/o-mně` → `/about`, `/první-setkání` → `/first`). Navbar links use Czech paths directly.

**Key directories:**
- `app/` — Routes: root page, about, first, practice, contact, error-page, not-found, plus API route (`api/contact/route.ts`)
- `components/` — Page content components (HomeContent, AboutContent, etc.), Navbar (responsive with hamburger menu), CleanModal/CleanModalMini (contact modals), Analytics (GA page view tracker)
- `hooks/useWindowDimension.ts` — Viewport width hook used for responsive rendering decisions
- `utils/` — `sendEmail.ts` (form submission to API), `gtag.ts` (Google Analytics wrapper)
- `assets/` — Static images imported directly into components (uses Next.js Image with blur placeholders)

**Page structure:** Each route has a server component (`page.tsx`) exporting metadata and rendering a `'use client'` content component. This keeps SEO metadata server-rendered while allowing client-side interactivity.

**Styling:** Tailwind utility classes with custom theme in `tailwind.config.js` (custom colors: `font-green`, `green-light`, `green-dark`; custom shadows: `soft`, `soft-lg`; background image: `motiv.png`). Additional animations and overlay styles in `styles/globals.css`.

**Contact flow:** Modal-based contact forms submit via `utils/sendEmail.ts` → `app/api/contact/route.ts` → Nodemailer (seznam.cz SMTP).

**SEO:** Metadata API with `title.template` in root layout. JSON-LD structured data (LocalBusiness). Sitemap generated by `next-sitemap` on postbuild. `robots.txt` and `sitemap.xml` in `public/`.

**Analytics:** Google Analytics (gtag) loaded via root layout with `usePathname()`-based route change tracking in `components/Analytics.tsx`.

## Environment Variables

Defined in `.env` (not committed): email credentials (`NEXT_PUBLIC_EMAIL`, `NEXT_PUBLIC_PASSWORD`) and GA tracking ID (`NEXT_PUBLIC_GA_TRACKING_ID`). Do not modify without asking first.
