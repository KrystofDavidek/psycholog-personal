## Project Overview

Personal website for a psychotherapist (Mgr. Petr Davídek) based in Brno, Czech Republic. All content is in Czech. The site uses Czech-language URL routing via Next.js rewrites (e.g., `/o-mn%C4%9B` → `/about`).

## Commands

- `npm run dev` — Start development server
- `npm run build` — Production build (automatically runs `next-sitemap` via postbuild)
- `npm run start` — Start production server
- `npm run lint` — ESLint (next/core-web-vitals)

## Architecture

**Stack:** Next.js 15.1 (Pages Router), React 18, TypeScript, Tailwind CSS 3

**Routing:** File-based Pages Router (`pages/`). Czech URL paths are mapped via rewrites in `next.config.js`. All page links use the `as` prop on `<Link>` to display Czech URLs.

**Key directories:**
- `pages/` — Routes: index, about, first, practice, contact, plus API route (`api/contact.ts`)
- `components/` — Navbar (responsive with hamburger menu), CleanModal/CleanModalMini (contact modals for desktop/mobile)
- `hooks/useWindowDimension.ts` — Viewport width hook used for responsive rendering decisions
- `utils/` — `sendEmail.ts` (form submission to API), `gtag.ts` (Google Analytics wrapper)
- `assets/` — Static images imported directly into components (uses Next.js Image with blur placeholders)

**Styling:** Tailwind utility classes with custom theme in `tailwind.config.js` (custom colors: `font-green`, `green-light`, `green-dark`; custom shadows: `soft`, `soft-lg`; background image: `motiv.png`). Additional animations and overlay styles in `styles/globals.css`.

**Contact flow:** Modal-based contact forms submit via `utils/sendEmail.ts` → `pages/api/contact.ts` → Nodemailer (seznam.cz SMTP). Redirects to `/kontakt` on success, `/error` on failure.

**SEO:** Each page has manual meta/OG/Twitter tags. Sitemap generated by `next-sitemap` on postbuild. `robots.txt` and `sitemap.xml` in `public/`.

**Analytics:** Google Analytics (gtag) loaded via `_app.tsx` with route change tracking.

## Environment Variables

Defined in `.env` (not committed): email credentials (`NEXT_PUBLIC_EMAIL`, `NEXT_PUBLIC_PASSWORD`) and GA tracking ID (`NEXT_PUBLIC_GA_TRACKING_ID`). Do not modify without asking first.
